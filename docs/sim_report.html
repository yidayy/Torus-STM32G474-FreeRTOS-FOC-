三、找到的 Bug：抗积分饱和

原写法把积分钳到 out_max：

if (integral > out_max) integral = out_max;      // 错

问题在于输出是 out = Kp·err + integral。当 Kp·err 已经 5 A、限幅 2.2 A 时，积分钳到 2.2，等误差降到 0，输出还是 2.2（满力矩），电机照样冲过头。

改成 back-calculation，输出饱和时把积分反推成"刚好不饱和"：

if (out > p->out_max) { out = p->out_max; p->integral = out - p_term; }
else if (out < -p->out_max) { out = -p->out_max; p->integral = out - p_term; }
效果：同样 Kp=0.094/Ki=1.31 下，反转超调从 63.2% 降到 0%。
这个 bug 在仿真里是"怎么调参数都压不下去的 30% 超调"，上板后的表现就是电机每次反向都冲一段才回来 —— 而且你会以为是参数没调好，一直调下去。

仿真没覆盖的东西（上板后必然遇到）：
① 电流环带宽限制 —— 仿真里电流环是理想的，实机 Kp=0.35 偏小，建议上板后把电流环 Kp 加到 2.0~2.4（ωc≈2 kHz）；
② 编码器噪声和机械共振；
③ 母线电压跌落。
所以 推荐值 0.094 是仿真最优，实机建议从 0.06 起步往上加，别直接抄 0.094。
