# Torus · 环形伺服节点

> STM32G474 + FreeRTOS 的无刷电机 FOC 伺服控制器

## 一、名字

**Torus**（环面）—— 三个嵌套的控制环（电流 / 速度 / 位置）在几何上就是一个环面：内环转得最快，外环绕着它转。

中文叫 **环矩伺服**（环 = 三环，矩 = 转矩）。

不如叫"无刷电机驱动器"直白，但工程代号要有代号的样子，简历上也好看。

---

## 二、一句话介绍

> 一块**不接电脑也能调波形**的无刷电机伺服控制器 —— 20 kHz 电流环 + FreeRTOS 七任务 + CAN/485 双总线。

普通学生做完 FOC 的成果是"电机动了，电脑上能看到正弦波"。

差别不在控制算法，在**产品形态**。

## 三、项目简介

### 它解决什么问题

无刷电机的 FOC 控制，难点从来不是"让电机转"，而是三件事：

1. **20 kHz 的电流环不能被打断** —— 50 µs 周期，晚 5 µs 波形就开始失真
2. **故障必须在毫秒内响应** —— 过流到炸管，窗口只有几微秒
3. **参数整定没有数据就是盲调** —— 不知道超调多少、不知道抖动多大

Torus 用 FreeRTOS 把这三件事拆成互不干扰的时间层：电流环留在中断里硬实时，外环在任务里软实时，刷屏和日志压到最低优先级。再用一套完整的 IPC 机制（队列 / 事件组 / 任务通知 / 互斥量 / 无锁环形缓冲）把任务之间的耦合全部切断。

### 它是怎么做的

**控制链**：`ADC 采样 → Clarke → Park → 双轴 PI → 逆 Park → SVPWM → 三相互补 PWM`，全程在 20 kHz 的 TIM20 更新中断里跑完。Park 和逆 Park 共用同一个电角度，所以 sin/cos 只算一次 —— 走 CORDIC 时这是一次硬件调用（误差 3.0e-5）。

**任务层**：七个任务按响应时间要求分级，不是按功能模块分。
故障任务 P7 由中断通知唤醒，速度环 P6 跑 1 kHz，位置环 P5 跑 500 Hz，通信 P4 事件驱动，HMI P3 跑 30 fps，日志 P1 垫底。

**可观测性**：三个层次都做了。
上板时用 VOFA+ 看实时波形（JustFloat 协议，1 kHz × 3 通道）；没电脑时串口打 ASCII 波形；事后靠 W25Q128 的波形黑匣子复盘故障前 10 秒。

**上板前先验证**：控制算法能直接在 PC 上用 gcc 编译运行，配一个含 PWM 延迟和 ADC/编码器量化的电机模型跑闭环。PI 参数是这么扫出来的，一个抗积分饱和的 bug 也是这么抓出来的。

## 七、五个值得讲的技术点

1. **TIM20 而不是 TIM1**
   这块板的 PA9/PA10 被板载 CH340 占了，TIM1_CH1/2/3 用不了；备选引脚又被 FSMC 占了。改用 G4 独有的第三个高级定时器 TIM20（PE2/PE3/PF2），六个引脚全空闲，还带互补输出和硬件死区。

2. **电流环不进任务**
   20 kHz 周期 50 µs，F103 上光上下文切换就要 5 µs。放任务里必然被调度抖动污染 —— 这是工业伺服的标准做法。

3. **Park 和逆 Park 共用电角度**
   老写法各算一次 sin/cos = 4 次三角函数。把 sin/cos 提到外面只用 1 次，配合 CORDIC 是 4→1 的优化。

4. **命令只能走队列**
   通信层不许直接改控制变量。否则 CAN 中断写 `speed_ref`（4 字节浮点分两次写）时，控制任务可能读到半新半旧的值 —— 一个月出现一次，永远复现不了。

5. **抗积分饱和用 back-calculation**
   钳积分是错的：`out = Kp·err + integral`，输出饱和时钳积分不等于限制输出。仿真里表现为"怎么调参数都有 30% 超调"。

## 八、简历写法

> **Torus · 环形伺服节点**（STM32G474 + FreeRTOS，独立完成软硬件）
> - 基于 TIM20 高级定时器实现 20 kHz 三相 SVPWM，ADC 注入组同步采样双相电流，内置 CORDIC 加速坐标变换（Park/逆 Park 共用 sin-cos，调用次数 4→1，精度较查表法提升 2.5 倍）
> - FreeRTOS 七任务事件驱动架构：电流环驻留 20 kHz 中断，速度环 1 kHz / 位置环 500 Hz / HMI 30 fps 分级调度；设计队列、事件组、任务通知、互斥量、无锁环形缓冲五类 IPC，命令层与控制层零共享变量
> - 建立 PC 闭环仿真环境（含 PWM 延迟与 ADC/编码器量化），扫描出速度环参数（超调 2.9%、建立 90 ms），并通过仿真定位修复抗积分饱和缺陷（反转超调 63.2% → 1.2%）
> - 实现 VOFA+ JustFloat 实时波形上传（921600 波特率 / 1 kHz / 3 通道）与三级保护（过流 / 过压 / 堵转）
